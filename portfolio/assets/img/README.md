# Your images go here 📸

Drop your own files into this folder using these **exact names** — the code
picks them up automatically. No PHP/CSS editing needed.

| File | Where it shows | Recommended size |
|---|---|---|
| `photo.jpg` | About-page portrait **and** the small badge on the home ID card | 800 × 1000 (portrait 4:5) |
| `project-javalearnhub.jpg` | Screenshot at the top of the JavaLearn Hub case study (Projects page) | 1200 × 750 |

## How to replace a placeholder

1. Prepare your image (crop to the size above; JPG or PNG).
2. Save it with the same name as the placeholder, e.g. `photo.jpg`.
3. Drop it in this folder, overwriting the placeholder.
4. Refresh the page. Done — every slot updates itself.

## Tips

- **JPG** for photos (small), **PNG/WebP** for screenshots with text (sharper).
- Keep each file under ~300 KB so pages stay fast — compress free at
  [squoosh.app](https://squoosh.app) or [tinypng.com](https://tinypng.com).
- If a file is missing, the slot falls back to the "JD" initials or hides itself —
  you'll never see a broken-image icon.
- **Adding a new photo later:** put the file here, then copy any existing
  `<img src="assets/img/…" onerror="…">` line to the spot where you want it.
